1. 시작하기

ZIP을 풀고 mobile.html 또는 web-deck.html을 브라우저에서 여세요.
각 HTML에 전체 데이터가 포함되어 인터넷 없이 실행됩니다.
두 화면을 오가는 링크를 사용하려면 같은 폴더에 두세요.
휴대폰 파일 앱의 단순 미리보기는 버튼과 저장을 지원하지 않을 수 있으므로
HTML 실행을 지원하는 브라우저로 여세요.

2. 이번 화면 개편

- 제목: 스크립트 연습.
- 크림 배경, 차콜 강조, 밝은 질문 카드.
- 응답은 별도의 따뜻한 회색 배경으로 구분.
- 오른쪽 위 랜덤 퀴즈.
- 유형·난이도 필터 대신 왼쪽 카테고리 목차.
- 모바일에서는 카테고리 목차를 펼쳐 선택.
- 여섯 단계는 눌러서 이동할 수 있는 별도 탐색 영역.
- 이전·다음은 화살표가 있는 버튼으로 표시.
- NG와 평가를 '피해야 할 응답'과 '응답 체크리스트'로 분리.
- Source / FactCheck, CLEAR/THINK 및 D1–D3 설명을 교육생 화면에서 제거.
  관련 데이터와 운영자 확인 사항은 JSON/CSV 및 이 안내에 유지.

3. 연습 카드 / 전체 스크립트 / 진행률

연습 카드: 질문 → 판단 → 1차 응답 → 재질문 → 2차 응답 → NG / 평가.
다음 화살표로 순서대로 보거나 여섯 단계 버튼으로 바로 이동합니다.
카드 아래 선택 메뉴와 좌우 화살표로 다른 질문을 선택할 수 있습니다.
평가 단계를 연 카드는 진행률의 '평가 단계 확인'에 반영됩니다.
이는 모든 단계를 읽었다는 인증 또는 퀴즈 통과와는 별개입니다.

전체 스크립트: 질문, ID, 태그 검색. 선택한 카드를 연습 화면에서 엽니다.
진행률: 모든 카드의 최신 통과·복습 결과와 누적 도전 횟수를 표시합니다.
카테고리 선택은 연습·퀴즈·목록에 적용되고 진행률은 전체 기준입니다.

기존 화면에서 저장한 통과·복습 기록은 같은 주소에서 이어집니다.
화면 개편 최초 실행 시 이전 유형·난이도 필터와 진행 중이던 라운드를
초기화합니다. 이미 저장한 학습 결과와 도전 횟수는 유지합니다.

4. 랜덤 퀴즈 — mobile.html

상단 오른쪽 랜덤 퀴즈를 누르면 선택한 카테고리로 새 라운드를 만듭니다.
전체 카테고리에서는 57개를 섞습니다. 한 라운드에 중복 카드가 없습니다.

힌트: 판단 포인트를 확인합니다.
I don't know: 즉시 Review에 저장하고 1차 응답을 보여줍니다.
Review: 복습 대상으로 저장하고 다음 카드로 넘어갑니다.
Clear: NG / 평가에서 기준 3개를 모두 체크하면 통과로 기록합니다.
모른다고 답한 카드는 이번 시도에 Clear로 바꾸지 않습니다.
Review 라운드에서 다시 도전해 통과할 수 있습니다.

Clear는 자기평가입니다. 음성 분석이나 자동 채점은 하지 않습니다.
'모름' 수는 Review 수에 포함되므로 두 수를 합산하지 마세요.
새로고침하면 동일한 카드, 공개 단계, 라운드 순서가 복원됩니다.
오른쪽 위 랜덤 퀴즈를 다시 누르면 새 라운드를 시작합니다.

진행률은 같은 브라우저·주소의 localStorage에 저장합니다.
파일 이동, 브라우저 데이터 삭제, 시크릿 모드에서는 기록이 사라지거나
달라질 수 있습니다. 저장이 차단되면 화면에서 알리고 연습은 계속됩니다.
초기화에는 확인창이 표시됩니다. 기기 간 동기화는 없습니다.

5. 발표용 화면 — web-deck.html

한 시나리오를 16:9 카드에 표시합니다.
카테고리 목차와 '질문 선택' 메뉴는 왼쪽에 모았습니다.
카드 아래에는 여섯 단계 버튼, 큰 이전·다음 화살표만 둡니다.
NG와 평가는 카드 안에서도 두 패널로 분리합니다.

발표 화면의 랜덤 퀴즈는 질문 순서를 섞어 교육생에게 구두로 질문하는
발표용 모드입니다. 채점 기록이 필요하면 mobile.html을 사용하세요.
'순서대로 보기'를 누르면 일반 발표 순서로 돌아갑니다.

Space / 오른쪽 화살표: 다음 단계, 마지막 단계에서는 다음 질문.
왼쪽 화살표: 이전 단계, 질문 단계에서는 이전 질문.
N / P: 다음 / 이전 질문.
Home: 현재 질문으로 돌아가기.
F: 전체 화면. Esc 또는 '전체 화면 닫기' 버튼: 종료.
질문 카드 자체를 누르면 공개되지 않습니다. 단계 버튼이나 화살표를 사용하세요.
단축키 안내는 화면 아래의 '키보드로 조작하기'에 접어두었습니다.

CSV 내 쉼표와 따옴표는 표준 CSV 규칙으로 이스케이프했습니다.

FactCheck
COACHING_REVIEW_REQUIRED  교육 담당자의 상황·표현 검토 필요
POLICY_CHECK_REQUIRED    해당 거점 정책·권한·후속 절차 확인 필요

공식 승인본으로 검증된 항목은 없습니다. Source의 공식 URL은 확인 경로이며,
내부 정책이나 해당 응대 문구의 공식 승인을 뜻하지 않습니다.
기능·출시·가격·법적 책임·개인정보·운영 정책을 이 예시 자체로 확정하지 않습니다.
응대 문장은 가상의 훈련용 예시이며 실제 고객이나 직원의 녹취가 아닙니다.
