스크립트 연습 — 크림 버전 검증 기록
2026-10-02 / 화면 Edition 02 / 데이터 v1.0

데이터와 기능
- 기존 57개 스크립트 내용 유지. H 14개, A 제외 유지.
- JSON/CSV와 두 HTML의 내장 데이터 일치 확인.
- 이전 버전의 진행률 기록을 유지하고 숨겨진 이전 유형·난이도 필터를 초기화.
- 카테고리 목차와 모바일 펼침·선택 후 접힘 확인.
- 교육생 화면에서 유형·난이도와 Source / FactCheck 표시 제거.
- 오른쪽 위 랜덤 퀴즈, 한 라운드 57개 중복 없음.
- 카테고리별 퀴즈, Review 전용 라운드, I don't know 저장 및 응답 공개.
- 평가 3개 확인 후 Clear 활성화. 모른다고 답한 시도는 Review로 유지.
- 새로고침 후 카드와 응답 단계 복원.
- Library ID 검색과 카드 열기.
- 320 / 390 / 768 / 1440px 너비에서 단계별 가로 넘침 없음.
- 질문·판단·응답·재질문·2차 응답·NG/평가 직접 이동.
- NG와 평가를 별도 패널로 구분.

발표용 화면
- 16:9 비율 유지.
- 1280×720 화면에서 주요 이전·다음 버튼이 화면 안에 표시됨.
- 57개 × 6단계, 총 342개 화면의 내용 넘침 없음.
- 발표용 랜덤 퀴즈의 57개 질문 중복 없음.
- 랜덤 모드의 카테고리 변경 및 순서대로 보기 복귀.
- 전체 화면 진입, 화살표 키 조작, Esc 종료 확인.
- 단축키 안내는 접힌 별도 영역으로 이동.

환경
- 실제 Chrome 브라우저 / macOS에서 실행.
- 네트워크 차단 file:// 실행, 저장 복원 확인.
- localStorage 차단 시 안내 및 기능 유지 확인.
- 검증 중 JavaScript 오류 없음.
- 실제 iPhone/Android와 Safari 실기기 검증은 수행하지 않음.

검증 범위
교육용 화면과 기능의 검증입니다. 거점 정책, 공식 정보, 실제 견적이나
법적 책임의 정확성을 인증한 것은 아닙니다. Source와 FactCheck는 화면에서
숨기고 원래 데이터 및 README의 운영자 안내에 유지했습니다.
