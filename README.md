# 스크립트 연습

Genesis 큐레이터를 위한 57개 고객 응대 시나리오. 크림 배경과 차콜 강조를 사용한 한국어 학습 도구입니다.

## 화면

- `/`: 연습 카드, 랜덤 퀴즈, 전체 스크립트, 진행률
- `/deck`: 16:9 발표 화면과 랜덤 질문
- 카테고리 목차, 여섯 단계 공개, NG / 평가 분리
- 진행률은 각 브라우저의 localStorage에 저장되며 계정 간 동기화는 없습니다.

## Vercel 배포

이 저장소를 Import합니다. `vercel.json`에 정적 사이트 설정이 포함되어 있습니다.
Framework Preset은 **Other**, Root Directory는 저장소 루트, Output Directory는 **public**입니다.
빌드와 패키지 설치가 필요하지 않습니다.

## 파일 구성

- `public/index.html`: 모바일 및 데스크톱 학습 화면
- `public/web-deck.html`: 발표 화면
- `data/`: 원본 JSON/CSV, 출처 대응표, 데이터 구성
- `docs/`: 운영 안내와 검증 기록

배포 대상은 `public/`입니다. 데이터·운영 문서는 저장소에서 관리합니다.
각 HTML에 시나리오가 포함되어 있어 실행 시 별도 API가 필요하지 않습니다.
데이터 변경 시 JSON/CSV와 두 HTML의 내장 데이터도 함께 갱신해야 합니다.

## 서비스 응대 개정 v1.1

57개 시나리오의 1차·2차 응답 114개를 고객 공감과 선택 지원 중심으로 다듬었습니다. C01에는 출퇴근과 가족 캠핑이라는 이용 예시를 반영했습니다. 수정된 문구는 `docs/service-responses-v1.1.txt`에서도 확인할 수 있습니다.
